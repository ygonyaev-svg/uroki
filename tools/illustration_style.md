# Эталон иллюстраций «Уроков» (утверждён Юрием 21.11.2026)

Все картинки к викторинам и заданиям рисуем в одном стиле. Образец: `docs/img/hp/dragon.webp`, `quidditch.webp`, `train.webp`.

## Стиль
- Классическая книжная иллюстрация: акварель + тушь (тонкий тёмный контур, мягкая заливка, лёгкая штриховка).
- Тёплый свет (огонь, лампы, закат), уютные детали: дерево, ткань, посуда, книги.
- Палитра: охра, коричневый, приглушённые красный и зелёный, тёплый жёлтый свет; для ночи и тревожных сцен — серо-синий.
- Горизонтально 4:3. Без надписей и букв (цифры — только если они и есть суть задания).
- Персонажи — свои, похожи на описание в книге, не на актёров фильма. Никаких кадров из фильмов и официальных иллюстраций.
- Внутри одного цикла герои одинаковые (одна внешность из картинки в картинку).
- Для «Найди ошибку»: ровно одна ошибка, крупная и заметная, всё остальное — как в книге.

## Промпт (Gemini, gemini.google.com, платный аккаунт Юрия)
Первый запрос цикла:
> Create an image: a classic book illustration in watercolor and ink, horizontal 4:3, no text. Warm, detailed, cosy, like an illustrated children's novel. Original character designs, not resembling any film actors. Scene: …

Следующие запросы в том же чате:
> Same style and the same original character designs. Create an image: a classic book illustration in watercolor and ink, horizontal 4:3, no words. Scene: …

Имена героев и детей в промпт не писать — только внешность (мальчик в круглых очках, рыжий мальчик, девочка с пышными каштановыми волосами, великан с бородой и т.п.).

## Файлы
- Скачать кнопкой «Скачать» (оригинал 2400×1792) → уменьшить до 1000 px по длинной стороне → WebP, качество 72 (~150–180 КБ).
- Класть в `docs/img/<тема>/<имя>.webp`; в коде у картинки класс `noico` не нужен, это `<img>`.
