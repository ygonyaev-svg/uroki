# Уроки для Ярика и Ани

Ежедневные уроки на iPad: математика, русский, чтение вслух, мир вокруг нас / история, логика, португальский и английский.
Программа построена по советским учебникам 1986–1992 годов, без идеологии.

Открыть: https://ygonyaev-svg.github.io/uroki/

Сборка: `python3 tools/build.py` → папка `docs/`.
